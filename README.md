# piper_control
A C++ robot motion control framework for Piper robotic arm.
## Goals
This project aims to implement:
- SO(3)
- SE(3)
- Robot Kinematics
- Jacobian
- Inverse Kinematics
- Robot Dynamics
- Trajectory Planning
- Motion Control
- State Estimation
- ROS2 Integration
## Development Environment
- C++17
- Eigen
- CMake
- Git
## Roadmap
Week 1:
- SO(3)
- SE(3)
- DH
- Forward Kinematics
Week 2:
- Jacobian
- Numerical IK
- DLS
- Singularity
